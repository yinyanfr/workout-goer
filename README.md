# Workout Goer 🏃

**AI thinks, you lift.**

Workout Goer is a web app that visualizes AI-generated workout plans. You feed it a structured JSON plan (from ChatGPT, Gemini, or any LLM), and it renders a clean, navigable week-by-week training schedule — cardio, strength, recovery, all in one place.

### [Live Demo](https://workout-goer.web.app)

---

## Features

- 🔐 **Google Sign-In** via Firebase Auth — your data, your account
- 📋 **Visual plan rendering** — 4 training phases as collapsible cards with cardio/strength/recovery tables
- 📅 **Weekly drill-down** — click any week to see that week's specific workouts
- ✍️ **JSON import** — paste AI-generated JSON, with a built-in code editor (syntax highlighting + line numbers)
- 📖 **/help page** — full JSON format reference with field tables and examples
- 🌙 **Dark mode** — toggle between light and dark, persisted
- 🌍 **i18n** — 简体中文 / English / Français / 日本語
- 🎨 **3D canvas landing page** — rotating wireframe toruses, pure Canvas 2D, zero libraries
- 👤 **User profile** — save your height, weight, age, and bio to Firestore
- 📱 **Responsive** — works on phones and desktops

## Getting Started

### Prerequisites

- Node.js 18+
- npm
- A Firebase project with Firestore and Auth (Google provider) enabled

### Install & Run

```bash
git clone https://github.com/yinyanfr/workout-goer.git
cd workout-goer
npm install          # also runs `umi setup` (generates src/.umi/)
npm run dev          # starts dev server at http://localhost:8000
```

### Build & Deploy

```bash
npm run build        # outputs to dist/
firebase deploy      # deploys to Firebase Hosting
```

### Firebase Setup

1. Create a project at [console.firebase.google.com](https://console.firebase.google.com/)
2. Enable **Authentication** → Google provider
3. Enable **Cloud Firestore** in `eur3` region
4. Replace the Firebase config in `src/services/index.ts` with your own
5. Deploy Firestore rules: `firebase deploy --only firestore:rules`

## How It Works

1. **Log in** with Google (top-right nav button)
2. **Use an AI tool** (ChatGPT, etc.) to generate a workout plan in JSON format — see the [Help page](https://workout-goer.web.app/help) or `/help` for the schema
3. **Go to /plans** and click "Import Plan" — paste the JSON (camelCase or snake_case, both accepted)
4. **Browse your plan** — 4 phases, expandable weeks, click any week for details
5. **Edit your profile** at `/user` — height, weight, age, bio

```
├── examples/        # plans.json, plan.d.ts, prompt.md (reference)
├── global.d.ts      # ambient types
└── .umi/            # auto-generated by Umi (never edit)
```
